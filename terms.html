Reel Poster – Terms of Service

Last updated: 13 October 2026

Reel Poster is a private desktop tool used only by the owner of the Badstrup Adventures channels (@badstrupadventures) to publish their own videos to their own YouTube, Instagram and TikTok accounts. It is not sold, offered or distributed to anyone else.

YouTube API Services

Reel Poster uses YouTube API Services. Anyone using Reel Poster agrees to be bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

TikTok

Reel Poster uses the TikTok Login Kit and Content Posting API to send the owner's own videos to their own TikTok account. Use of TikTok is subject to the TikTok Terms of Service.

Use

Reel Poster may only be used to upload videos that the user owns or has the rights to, to channels and accounts the user controls. Every upload is prepared and approved by the user before it is published. The user is responsible for the content they publish and for following the rules of each platform.

Data

How Reel Poster handles data is described in the Reel Poster Privacy Policy.

No warranty

Reel Poster is provided as is, without any warranty. Access can be removed at any time in the security settings of each connected account, and the tool can be removed by deleting its folder.
